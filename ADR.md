# Architecture Decision Records

This file records the significant architecture and technology decisions made for
**node-starter** so far. It is a single-file ADR log: newest decisions at the bottom, each
entry self-contained.

## About this log

Status values: **Accepted** (in force), **Superseded**, **Deprecated**, **Proposed**.

Format per entry: Context → Decision → Consequences (the trade-off, good and bad) →
Alternatives considered.
